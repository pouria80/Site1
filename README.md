# PooriTel

## Active project

`pooritel-hub-final/` is the current customer dashboard / PooriTel Hub prototype.

Run it with:

```powershell
cd pooritel-hub-final
npm install --registry=https://registry.npmmirror.com
npm run dev
```

## Repository structure

- `pooritel-hub-final/` — active dashboard project
- `pooritel-site-login/` — login project
- `archive/dashboard-legacy/` — archived dashboard prototypes and earlier experiments

Legacy dashboard builds are kept only for reference and are not part of the active project.

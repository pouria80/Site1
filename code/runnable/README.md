# codenew runnable builds

- `codenew-v2-exact` — wraps `code/codenewv2.txt` as the exact single-file React/Vite build.
- `codenew-v1-reconstructed` — runs `code/codenew.txt` with a compatibility layer because the TXT only contains the page component and references missing external component files.

Run either folder with `npm install` then `npm run dev`.

# PooriTel codenew v2 — exact runnable build

This folder wraps `code/codenewv2.txt` as a Vite + React project without changing the source UI code.

## Run

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Notes

The design references the original Qwen-hosted image assets used by the source file, so those images require internet access while previewing.

# PooriTel Admin Beauty Test 02

Experimental visual direction: **Constellation Admin**.

This is a standalone React/Vite prototype and does not import or modify the production admin preview.

## Run

```bash
npm install
npm run dev
```

Vite runs on port `5198`.

## Visual concepts

- Connected constellation instead of a conventional dashboard grid.
- Central GMV orb with concentric kinetic rings.
- Decision nodes for seller, listing, order, payout and verification workflows.
- Glassmorphic decision workspace with evidence and approval actions.
- Platform wallet represented as a secondary energy core.
- Animated signal stream and trust field.
- Light/dark and FA/EN modes.
- Reduced-motion support.

The prototype intentionally uses CSS-driven motion rather than a heavy WebGL dependency so the visual direction can be evaluated quickly before choosing a production rendering stack.

# PooriTel Admin Beauty Test

Independent visual experiment. It does not modify or import the active customer dashboard.

## Run

```bash
npm install
npm run dev
```

Vite uses port `5188`.

## Direction

- Aurora / liquid-glass layers
- Orb-centered brand motion
- Sparse decision-oriented information architecture
- Animated trust / finance surfaces
- Light and dark modes
- EN / FA language switch
- Centered glass decision modal
- Responsive layout

This folder is a design experiment only; keep the production admin preview untouched until a visual direction is approved.

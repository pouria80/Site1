# PooriTel Admin Preview

Standalone React + Vite preview for the PooriTel Admin Command Center.

## Run

```powershell
npm install
npm run dev
```

Open the Vite URL shown in the terminal (this preview uses port 5174).

## Included V1 architecture

- Overview / Control Center
- Users
- Sellers
- Seller Requests with review drawer
- Verification
- Products
- Orders
- Finance
- Risk & Trust
- Support
- Admins & Roles

This is a UI/UX preview with mock data only. It is intentionally isolated from the production PooriTel site and does not modify the existing authentication, database, Worker, or customer Hub.

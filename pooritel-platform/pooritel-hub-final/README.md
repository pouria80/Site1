# PooriTel Hub Final

Standalone React + Vite customer dashboard prototype.

## Run

```powershell
npm install --registry=https://registry.npmmirror.com
npm run dev
```

Open the local Vite URL shown in the terminal.

## Important

This project is independent of the previous `codenew` builds. It does not load `codenew.txt`, `codenewv2.txt`, GitHub Raw files, `prepare-source.mjs`, Framer Motion, or any backend service.

The UI includes:
- Right-fixed collapsible sidebar
- FA/EN language switcher that keeps the sidebar on the right
- Light/Dark theme
- Cinematic order signal with animated core/orbits
- Compact multi-currency display wallet
- Animated Quick Actions
- Personalized customer space
- Product discovery cards with interactive hover states
- Activity journey
- Support and ticket entry
- Responsive mobile drawer
- Mock data only; ready for later API integration
